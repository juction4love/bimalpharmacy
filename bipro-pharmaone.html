What is BIPRO PharmaOne?

BIPRO PharmaOne is a single-PC, fully offline retail pharmacy ERP (Enterprise Resource Planning) application built for Nepal. All pharmacy data is stored in a secure local PostgreSQL database on your own computer. No cloud account, no internet subscription, and no third-party server receives your pharmacy data during normal operation.

The application is built with .NET 10 and PostgreSQL 17 and runs on Windows 10 and Windows 11 (64-bit). Both the database engine and the .NET runtime are bundled in the installer — customers do not need to install or configure any software separately.

Regulatory note: Sales documents are labelled CHALLAN (चालान). BIPRO PharmaOne is not IRD-approved, CBMS-certified, DDA-approved, or an authorised VAT billing system. Live CBMS transmission is not enabled in this release. It is a local record-keeping and management tool for retail pharmacy operations.

Features

Sales and Billing

Cash and credit sales with FEFO batch allocation. Challan printing (A4 and 80 mm thermal). Full sales history, cancellations, and reversals. Post-expiry dashboard and billing access retained.

Purchase Management

Cash and credit purchases with inline supplier quick-add. Duplicate detection. Purchase receipt numbers (PRN). Full purchase history. Discard unfinalized drafts. Credit note processing.

Inventory and Batch Tracking

FEFO (First Expiry First Out) stock allocation. Batch-level stock and cost tracking. Expiry monitoring with EXPIRED / NEAR_EXPIRY / VALID classification. Physical stock counts. Reorder level alerts. Low stock and dead stock reports.

Supplier and Customer Management

Unified party master — same PAN/VAT links customer and supplier records. Customer and supplier ledgers, outstanding dues, and statement generation. Advance payment and receipt processing. Credit limit and payment rules.

Sales and Purchase Returns

Sales returns linked to original invoice line items — exact batch and cost reversal. Purchase returns with debit note and batch restoration. Supplier claim and claim recovery register.

Accounting and Double Entry

Full double-entry general ledger. Automatic journal posting on every transaction (sale, purchase, return, receipt, payment, expense). Closed-period protection. Trial balance, profit and loss, and balance sheet.

Finance and Cash Management

Customer receipts, supplier payments, expense records, other income. Fund transfers between payment methods. Cash, bank, and digital payment tracking. Day book, cash book, and bank book.

Reports and Analytics

Purchase book, sales book, VAT register, party statements, inventory valuation, gross profit, payment method reconciliation. Daily summary and operational dashboard KPIs.

Controlled Drug Register (CDR)

Automatic dispensing entries posted on sale finalization. Automatic receipt entries posted on purchase finalization. Nepal DDA schedule A–D controlled substances only. Each entry is immutable after save. Manual corrections via ADJUSTMENT entries.

Prescription Management

Immutable prescription records with product linkage. Prescription register for controlled drug dispensing traceability.

Backup and Restore

Daily automatic backup (last 30 kept). Manual backup on demand. Backups saved to %LOCALAPPDATA%\BIPRO PharmaOne\Backups. Pre-upgrade backup created automatically before every version upgrade. Restore workflow with verified integrity check.

Printing and Documents

A4 and 80 mm thermal cash memo printing. Official print mark (ORIGINAL / COPY). Reprint history. Report printing. Keyboard shortcuts for fast workflow (F1–F12).

Business Settings

Business profile (name, address, PAN/VAT, drug licence). Fiscal year management. Product categories, manufacturers, generics. CBMS configuration page (mock mode; live IRD transmission not enabled).

Licensing and Activation

30-day free trial included. RSA-2048 offline license with device binding. Email-based activation via admin@bimalpharmacy.com.np. Annual license with 30-day renewal reminder. Post-expiry: Dashboard and Sales Billing always accessible.

Installation guide

The installer handles all required components automatically. You do not need to install PostgreSQL or .NET separately.

  1. Download BIPRO_PharmaOne_Bundled_v1.0.13.exe using the Download button above.
  2. Optionally verify the SHA-256 checksum as shown above.
  3. Right-click the installer and select Run as administrator, or accept the User Account Control (UAC) prompt if shown. PostgreSQL requires administrator rights to install as a Windows service.
  4. Follow the setup wizard. PostgreSQL 17.11 and the .NET 10 Runtime install automatically in the background — you do not need to enter any database passwords or connection strings during installation.
  5. When setup finishes, launch BIPRO PharmaOne from the Start Menu or the desktop shortcut.
  6. On first launch, the First-Run Setup Wizard opens automatically.

First-run setup wizard

The first-run wizard runs only on a new installation. It collects your pharmacy information and creates your Administrator account.

  1. Enter your Business Name, address, and phone number. Optionally enter your PAN/VAT number and drug licence number.
  2. Create an Administrator username and password. This is your BIPRO application login — it is separate from Windows and from PostgreSQL. Choose a password you can remember; you will use it every day.
  3. Set your active Fiscal Year (Nepali BS year).
  4. Set your starting Cash Memo number.
  5. The application database is created and initialized automatically. When the wizard finishes, the main Dashboard opens.

Remember your Administrator password. If you forget it, recovery requires the maintenance-access credential which is set separately. Write your password down and store it securely.

Upgrading from an earlier version

Run the new installer over the existing installation. The installer:

  • Detects the existing installation and upgrades application files in place.
  • Creates a verified backup of your database before applying any database changes.
  • Applies only new approved database migrations — existing data is never deleted or overwritten.
  • Preserves your business profile, products, purchases, sales, accounting journals, settings, and license.

Never delete the PostgreSQL data directory or uninstall PostgreSQL during an upgrade. Your entire pharmacy database lives in the PostgreSQL data directory. Deleting it permanently destroys all your data. The installer does not delete PostgreSQL or its data under any normal upgrade scenario.

First-time configuration

After the first-run wizard completes, configure these settings before recording real transactions:

  1. Business profile: Go to Settings → Business Profile. Verify your pharmacy name, address, PAN/VAT, and drug licence number. These appear on printed challans.
  2. Fiscal year: Go to Settings → Fiscal Years. Confirm the active fiscal year matches your Nepal BS fiscal year.
  3. Products: Go to Inventory → Products. Add your medicines and products. Mark controlled substances with the Controlled Drug flag so they are automatically posted to the Controlled Drug Register.
  4. Suppliers and customers: Go to Parties → Suppliers and Parties → Customers. Add your suppliers first so they are available during purchase entry.
  5. Printer settings: Go to Settings → Printing. Select your default printer and paper size (A4 or 80 mm thermal). Print a test challan to verify the layout.
  6. Backup settings: Go to Settings → Database Backup. Confirm the backup folder. The application saves daily automatic backups. Copy backups to a USB drive or external disk regularly.
  7. Licensing: The application starts with a 30-day free trial. After the trial, use Activate License from the Dashboard to begin the activation process by email.

Daily operation guide

Recording a purchase

  1. Go to Purchases → New Purchase (or press F7).
  2. Select or add the supplier. Enter the supplier invoice number and purchase date.
  3. Add each medicine line: select product, enter batch number, expiry date, quantity, free quantity if applicable, and purchase rate.
  4. Select payment method (Cash / Bank / Credit).
  5. Click Finalize Purchase. Stock is posted to inventory, the supplier ledger is updated, and accounting journals are created automatically. If the purchase includes controlled drugs, CDR receipt entries are posted automatically.

Recording a sale (Cash Memo / Challan)

  1. Go to Sales → New Sale (or press F2 for cash, F3 for credit).
  2. Optionally enter the customer name.
  3. Search for each medicine and enter the quantity. The system allocates stock using FEFO — nearest-expiry batches are used first.
  4. Apply discounts if applicable. Enter the payment method.
  5. Click Finalize Cash Memo. The challan is printed automatically. Stock is deducted, the customer ledger is updated, and accounting journals are created. CDR dispensing entries are posted automatically for controlled drugs.

Returns

  • Customer returns: Go to Sales → Sales Returns. Select the original invoice, choose the item and quantity to return. Batch stock and accounting are reversed exactly.
  • Purchase returns: Go to Purchases → Purchase Returns. Select the original purchase. The supplier ledger and batch stock are updated.

Reports and accounts

  • Daily summary: Dashboard → Today's Work Report
  • Sales book: Reports → Sales Book
  • Purchase book: Reports → Purchase Book
  • Inventory: Inventory → Inventory Valuation or F8
  • Profit and loss: Accounts → Profit and Loss
  • Balance sheet: Accounts → Balance Sheet
  • Party statements: Parties → Customer / Supplier Statement

Controlled Drug Register

Go to Settings → Controlled Drug Register to view the full dispensing and receipt history for all controlled substances. Entries are posted automatically on every sale and purchase finalization. Manual ADJUSTMENT entries can be added if needed. No entry can be edited or deleted after save — this is required by Nepal DDA regulations.

Backup

Go to Settings → Database Backup to run a manual backup at any time. Automatic daily backups run in the background. Backup files are saved to %LOCALAPPDATA%\BIPRO PharmaOne\Backups. Copy these files to a USB drive, external disk, or another location regularly. The application keeps the last 30 automatic backups.

Your data and backups

BIPRO PharmaOne stores all pharmacy data in a local PostgreSQL database on your PC. No data is sent to any remote server during normal operation.

  • Database location: The PostgreSQL data directory is managed by the Windows PostgreSQL service. Do not move, rename, or delete this directory.
  • Backup location: %LOCALAPPDATA%\BIPRO PharmaOne\Backups (for example C:\Users\YourName\AppData\Local\BIPRO PharmaOne\Backups). Backups are .pgdump files — do not delete them manually unless you have verified copies elsewhere.
  • Upgrade safety: The installer creates a verified backup automatically before applying any database migrations. If the backup fails, the upgrade stops safely without touching the database.
  • Restore procedure: To restore from a backup, go to Settings → Database Backup → Restore. Select the backup file. The application verifies the backup before restoring and reports any errors.

Keep copies of your backups off the computer. If your PC fails, backups stored only on the same machine may be lost along with everything else. Copy backup files to a USB drive or external disk at least weekly.

Free trial and activation

New installations of BIPRO PharmaOne start a 30-day free trial automatically. No registration is required during the trial. The trial status is shown in the application status bar.

To activate after the trial:

  1. Open the Dashboard and click Activate License.
  2. The dialog generates an activation request containing your pharmacy name, installation identifier, and registration details.
  3. Email this request to admin@bimalpharmacy.com.np.
  4. After the owner reviews and approves the request, a signed license key is returned by email.
  5. Paste the key in the same activation dialog to activate.

Privacy note: The activation request intentionally includes your pharmacy details and installation metadata so the owner can verify the request. This information is shared with admin@bimalpharmacy.com.np during the activation email exchange only. Normal day-to-day operation of the application does not send any data to any server.

License verification is performed offline using RSA-2048 device binding — no internet is needed for daily use after activation. A license is tied to this installation and cannot be transferred to a different machine without a new key.

Post-expiry access: Dashboard and Sales Billing remain accessible after expiry. Purchase, Inventory, Returns, and Claims require a renewed license. Renewal reminders appear on the Dashboard starting 30 days before expiry.

Frequently asked questions

The installer asks for a password during installation. What do I enter?

The installer sets up PostgreSQL automatically. You are not asked to enter a PostgreSQL password. If a PostgreSQL-related dialog appears requesting a superuser password, it is from the standard PostgreSQL installer component — accept the default or leave it blank and click Next. For the BIPRO application Administrator password, the first-run wizard inside BIPRO will ask you to create your own username and password after installation is complete.

I forgot my BIPRO Administrator password. How do I reset it?

Password reset requires the maintenance-access credential that is configured separately. Contact admin@bimalpharmacy.com.np for assistance. Do not uninstall BIPRO PharmaOne to try to reset the password — uninstalling does not reset the database password and may cause additional problems.

I upgraded to a new version. Where is my data?

Your data is preserved. The installer upgrades only the application files and applies new database migrations safely. Your products, purchases, sales, accounting journals, settings, and license are all retained. If the upgrade applied successfully but you cannot see recent data, go to Settings → Database Backup and restore from the most recent backup.

The application says it cannot connect to the database. What should I do?

The PostgreSQL service may have stopped. Open Windows Services (search for "Services" in the Start Menu), find the PostgreSQL service (usually named "postgresql-x64-17"), and start it. Then relaunch BIPRO PharmaOne. If the service is running but the error persists, check that your Windows user account has not had its permissions changed.

I reinstalled Windows. How do I recover my data?

If you have backup files (.pgdump files from %LOCALAPPDATA%\BIPRO PharmaOne\Backups or from a USB drive), install BIPRO PharmaOne fresh on the new Windows installation. Then go to Settings → Database Backup → Restore and select your backup file to restore your pharmacy data.

My printer is not printing correctly. What do I do?

Go to Settings → Printing and verify the selected printer and paper size. For 80 mm thermal printing, select the thermal printer and choose Thermal (80 mm) paper. For A4 printing, choose your laser or inkjet printer and A4 paper. Print a test challan. Printer compatibility is tested with common laser and 80 mm thermal printers but cannot be verified for every model.

Can multiple computers share the same database?

BIPRO PharmaOne is a single-PC application. Multi-user network access from multiple computers is not available in the current version. All transactions are recorded from the one PC where the application is installed.

Does BIPRO PharmaOne submit bills to IRD or CBMS?

No. Live IRD/CBMS transmission is not enabled in this release. The CBMS settings page is included for future configuration. Sales documents are labelled CHALLAN and are not government-approved VAT invoices. BIPRO PharmaOne is a local pharmacy management tool, not a certified IRD billing system.

The 30-day trial has expired. Can I still use the application?

Yes, partially. After the trial expires, the Dashboard and Sales Billing remain fully accessible. Purchase entry, Inventory management, Returns, and Claims are restricted until a license is activated. Email admin@bimalpharmacy.com.np to begin the activation process.

Known limitations

  • Single-PC local setup only. Multi-user networking is not available in this version.
  • Sales documents are labelled CHALLAN, not VAT invoice. This application is not a substitute for a government-approved IRD billing system.
  • Printer compatibility is tested with common laser and thermal printers but not verified across all printer models.
  • Nepali BS date entry is supported for expiry fields. Full BS-calendar input for all date fields may be added in a future version.
  • Activation requires email exchange with the owner. There is no instant automated online activation in this release.
  • The 30-day trial is machine-keyed. Reinstalling on the same machine does not reset the trial period.
  • The Controlled Drug Register UNIQUE constraint on (reference_id, reference_table) is enforced at the application level only — the database table does not have a UNIQUE index on these columns in this release. Duplicate entries in a concurrent scenario (extremely unlikely on a single-PC installation) would require a manual ADJUSTMENT correction.

  • Supplier add: Parties → Suppliers → Add New
  • Customer add: Parties → Customers → Add New
  • Party statement: Parties → Statement — कुनै पनि supplier वा customer को ledger हेर्न
  • Outstanding dues: Parties → Outstanding — कुन customer ले कति बाँकी छ र कुन supplier लाई कति तिर्नु छ
एउटै PAN/VAT number भएको customer र supplier एउटै Party मा जोडिन्छ।
११. Inventory र FEFO

FEFO (First Expiry, First Out): Sales finalize हुँदा system ले automatically सबैभन्दा चाँडो expire हुने batch पहिले allocate गर्छ।

  • Stock check: Inventory → Stock Balance — हाल कुन product कति stock छ
  • Expiry monitoring: Inventory → Expiry Monitor — expire हुन लागेका batches
  • Low stock alert: Dashboard मा low stock products देखिन्छ
  • Stock adjustment: Inventory → Stock Adjustment — गल्ती सुधार्न वा expired stock write-off गर्न
  • Physical count: Inventory → Stock Count — physical count गरेर system stock reconcile गर्न
  • Inventory valuation: Inventory → Inventory Valuation (वा F8)
१२. Accounting र Finance

BIPRO PharmaOne मा double-entry accounting automatically हुन्छ — हर transaction मा balanced journal entry automatically post हुन्छ।

  • Customer receipt: Finance → Customer Receipt (वा F4) — customer ले payment दिएमा
  • Supplier payment: Finance → Supplier Payment — supplier लाई payment गरेमा
  • Expense: Finance → Expense — pharmacy को खर्च record गर्न
  • Fund transfer: Finance → Fund Transfer — Cash/Bank बीच transfer
  • Trial Balance: Accounts → Trial Balance
  • Profit and Loss: Accounts → Profit and Loss
  • Balance Sheet: Accounts → Balance Sheet
  • Day Book: Accounts → Day Book
१३. Controlled Drug Register (CDR)

Nepal DDA schedule A–D मा पर्ने controlled substances का लागि CDR automatically maintain हुन्छ।

  • Sale finalize हुँदा dispensing entry automatically post हुन्छ।
  • Purchase finalize हुँदा receipt entry automatically post हुन्छ।
  • CDR entries immutable हुन्छन् — save भएपछि edit वा delete गर्न मिल्दैन।
  • गल्ती भए ADJUSTMENT entry use गर्नुहोस्: Settings → Controlled Drug Register → Add Correction
CDR entry post हुन product को "Controlled Drug" flag checked हुनु पर्छ। Products setup गर्दा नबिर्सनुहोस्।
यदि CDR post गर्न कुनै technical error आयो भने application मा warning toast देखिन्छ। Sale/Purchase finalized भइसकेको हुन्छ — CDR Register page बाट manual correction add गर्नुहोस्।

१५. Printing

BIPRO PharmaOne ले A4 र 80 mm thermal paper दुवैमा print गर्न सक्छ।

  • Printer setup: Settings → Printing → Default Printer छान्नुहोस्।
  • Paper size: A4 वा Thermal (80mm) छान्नुहोस्।
  • Reprint: Sales → Sales History → Print — पहिलेको challan reprint गर्न।
  • Print shortcut: F9 — current view print गर्न।
Thermal printer को लागि paper width 80mm set गर्नु पर्छ। Printer ले Windows मा correctly install भएको हुनु पर्छ।
१६. Backup र Restore

Automatic Backup: Application ले daily automatically backup लिन्छ। Last 30 backups सुरक्षित रहन्छन्।

Manual Backup:

  1. १
    Settings → Database Backup मा जानुहोस्।
  2. २
    Backup Now click गर्नुहोस्।
  3. ३
    Backup file %LOCALAPPDATA%\BIPRO PharmaOne\Backups मा save हुन्छ।

Restore:

  1. १
    Settings → Database Backup → Restore मा जानुहोस्।
  2. २
    Backup file select गर्नुहोस्।
  3. ३
    Confirm गर्नुहोस्। Application ले backup verify गरेर restore गर्छ।
महत्त्वपूर्ण: Backup files USB drive वा external disk मा copy गर्नुहोस्। Computer नै बिग्रिए एउटै machine मा भएका backup files पनि नष्ट हुन सक्छन्।

समस्यासमाधान
Database connect हुँदैन Windows Services मा "postgresql-x64-17" service start छ कि छैन check गर्नुहोस्। Start गर्नुहोस् र BIPRO restart गर्नुहोस्।

Stock negative देखिन्छ Inventory → Negative Stock Reconciliation use गर्नुहोस्। Opening stock purchase entry add भएको छैन भने थप्नुहोस्।
Upgrade पछि data देखिँदैन Settings → Database Backup → Restore बाट last backup restore गर्नुहोस्।
CDR entry post भएन Application मा warning toast आउँछ। Settings → Controlled Drug Register बाट manually ADJUSTMENT entry add गर्नुहोस्।
