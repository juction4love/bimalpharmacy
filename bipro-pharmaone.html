Step-by-Step Installation Guide

Follow these steps to set up BIPRO PharmaOne on your Windows computer:

  1. 1

    Install PostgreSQL 17 for Windows (Prerequisite)

    Download the official PostgreSQL 17 Windows installer from postgresql.org/download/windows.

    Run the PostgreSQL installer with standard default settings (Port 5432, Superuser postgres). Keep note of your administrative postgres master password. (Note: BIPRO PharmaOne requires PostgreSQL to be installed on your computer before running the setup wizard.)

  2. 2

    Download BIPRO PharmaOne Installer

    Download the public release file: BIPRO_PharmaOne_Free_Setup_v1.0.0.exe (~72.78 MB) via official GitHub Release.

    Optionally verify the SHA-256 hash using the instructions in the Verify Download section below.

  3. 3

    Run Installer as Administrator

    Right-click BIPRO_PharmaOne_Free_Setup_v1.0.0.exe and select "Run as Administrator".

    The installer checks for PostgreSQL presence, copies application binaries, automatically provisions the verified local database schema, and securely configures credentials in Windows Credential Manager.

  4. 4

    Open BIPRO PharmaOne

    Launch BIPRO PharmaOne from the newly created Desktop shortcut or Start Menu.

  5. 5

    Complete First-Run Pharmacy Setup

    Enter your pharmacy business information: Business Name, Address, Phone Number, optional PAN/VAT / DDA number, Fiscal Year, and starting Challan number.

  6. 6

    Add Products & Begin Daily Billing

    Create your medicine master list, setup supplier and customer accounts, and begin recording purchases and issuing sales challans.

  7. 7

    Take Regular Backups

    Regularly create database backups from inside the software (Settings / Backup) and store backup files on an external USB drive.

Data Safety & Backup Responsibility

Mandatory Backup Notice

"Your pharmacy data is stored locally on your computer. Keep regular backups and store at least one backup in a separate safe location."

Because BIPRO PharmaOne runs 100% offline, only you have access to your database. If your hard drive fails or Windows crashes, data can only be recovered from your own backup copies.

Important: Uninstalling or reinstalling the application should never be treated as a substitute for database backups. Always click the Backup button to export your .backup file and save it to an external USB flash drive regularly.

Frequently Asked Questions (FAQ)

Is BIPRO PharmaOne really 100% free?

Yes. BIPRO PharmaOne Clean Public Edition is free for operational use by retail pharmacies and clinics. There are no monthly subscriptions, hidden fees, or time-limited trials.

Does the software need an active internet connection?

No. BIPRO PharmaOne runs on a local PostgreSQL database on your PC. It is built offline-first and functions completely without internet.

Where is my pharmacy customer and sales data stored?

BIPRO PharmaOne stores its operational pharmacy database locally in PostgreSQL on your computer. Normal day-to-day operation does not require cloud database storage.

Does BIPRO PharmaOne print authorized IRD Tax Invoices?

No. Current sales document terminology is CHALLAN (चालान / बिल). The software is not certified as an authorized Nepal Tax Invoice or CBMS system. It is designed for internal retail pharmacy management, sales challans, estimates, inventory, and double-entry accounting.

Why do I need to install PostgreSQL 17?

PostgreSQL is a world-class, free, open-source database engine that safely stores your medicines, stock, customers, bills, and accounting ledgers. Installing PostgreSQL 17 ensures your pharmacy database remains fast, reliable, and secure.

How do I transfer my data to a new computer?

You can create a backup using the Backup tool inside the software, copy the .backup file to a USB drive, install PostgreSQL and BIPRO PharmaOne on the new PC, and restore your database.
