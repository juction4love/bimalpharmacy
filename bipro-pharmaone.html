What is BIPRO PharmaOne?

BIPRO PharmaOne is a single-PC, offline retail pharmacy management application. It stores all data in a local PostgreSQL database — no cloud account, no internet subscription, no third-party server receives your pharmacy or patient data during normal operation.

  • Sales: Cash sales, credit sales with customer ledger, challan history, and sales returns.
  • Purchases: Cash and credit purchases, purchase returns, and supplier claims.
  • Inventory: Batch tracking (FEFO), stock adjustments, physical count, expiry warnings, and negative-stock recovery.
  • Accounting: Double-entry general ledger, trial balance, profit & loss, balance sheet, and cash/bank books.
  • Finance: Customer receipts, supplier payments, expense records, and other income.
  • Reports: Purchase book, sales book, party statements, outstanding dues, and inventory valuation.
  • Backup: Daily automatic backup and manual backup with the option to restore from a local archive.

Regulatory note: Sales documents are called CHALLAN (चालान). BIPRO PharmaOne is not IRD-approved, CBMS-certified, DDA-approved, or an authorized tax invoice system. It is a local record-keeping tool.

Installation instructions

  1. Download BIPRO_PharmaOne_Setup_v1.0.3.exe using the button above.
  2. Verify the SHA-256 checksum (see below) if you want to confirm the file is unmodified.
  3. Run the installer. Accept the User Account Control (UAC) prompt if asked — PostgreSQL requires administrator rights to install as a Windows service.
  4. Follow the setup wizard. PostgreSQL 17 and the .NET 8 Runtime are installed automatically if not already present.
  5. When setup finishes, launch BIPRO PharmaOne from the Start menu or desktop shortcut.
  6. On first run, the setup wizard asks for your business name, address, phone number, and optional PAN/VAT and drug licence numbers. It also creates an Administrator account (username and password) for the application.
  7. Set your fiscal year, starting challan number, and beginning stock as instructed by the wizard.

Never uninstall and reinstall to reset data. Reinstalling does not erase the database. Use the in-app backup and restore workflow to manage your data safely. Keep backup copies in a separate safe location (USB drive, external drive, or cloud storage of your choice).

Your data stays on your computer

BIPRO PharmaOne stores all pharmacy data — sales, purchases, customers, products, accounting journals — in a local PostgreSQL database on your PC. No data is sent to any remote server during normal operation. The application does not require a login to a cloud service to function.

Backup files are saved to a folder on your computer. You can copy them to any storage of your choice. The application does not upload backups automatically.

The CBMS transport feature (if present in a future version) has live sending disabled in the current release.

  • 55 database migrations applied; full clean-install acceptance test passed.

Known limitations

  • Single-PC local setup only. There is no built-in multi-user networking or remote access in the current version.
  • Sales documents are labelled CHALLAN, not VAT invoice. This application is not a substitute for a government-approved billing system.
  • Printer compatibility is tested with common laser and thermal printers but not verified across all printer models.
  • Nepali BS date entry is supported for expiry fields. Full BS-calendar input for all date fields may be added in a future version.
